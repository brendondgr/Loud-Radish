Speech model

Language

A two-letter code. Setting it explicitly is more reliable than detection, which occasionally switches language mid-talk on a technical term.

1 is greedy and fastest. Higher is more accurate and proportionally slower — raise it only if the real-time factor has room.

Terms and names

Paste the speaker's name, the venue, and any jargon before the talk. The model is biased toward these spellings, which is the single most effective thing available for a seminar full of proper nouns it has never seen.

Gives the model continuity across buffer boundaries. Occasionally lets a mistake reinforce itself, so turn it off if the same error keeps recurring.

Committing text

Text is committed once consecutive passes agree on it. Committed text never changes; the tentative tail is replaced wholesale each pass. These control that trade-off between how fast text settles and how often it settles on the wrong thing.

2 is the working default. 3 commits more slowly and revises less.
