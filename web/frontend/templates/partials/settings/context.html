These settings control that selection. The transcript clean-up used to sit here and no longer does. This tab is about what the assistant is *given*; the clean-up is about what it *writes*, and it now shares the Rewriting tab with the dictation tidy, which had no home in this dialog at all (D-068). #}

Budget

The transcript grows without limit; the model's context does not. Material is assembled in priority order until this budget is spent — the question, then the most recent speech verbatim, then summaries of everything before it.

Rolling summaries

Produces the outline in the assistant pane, and is what lets a question about the first twenty minutes still be answerable two hours in.

Glossary

Picks out jargon as it is introduced and defines it from how the speaker used it, which is usually more useful than a textbook definition.

Retrieval
