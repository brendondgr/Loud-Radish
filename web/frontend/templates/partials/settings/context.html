{# Context: what the assistant is given when it answers. A two-hour talk does not fit in any context window, so the question is never "send everything" but "send the right part". These settings control that selection. #}

Budget

The transcript grows without limit; the model's context does not. Material is assembled in priority order until this budget is spent — the question, then the most recent speech verbatim, then summaries of everything before it.

s

Questions are usually about what was just said, so the tail is sent exactly rather than summarised.

Rolling summaries

Produces the outline in the assistant pane, and is what lets a question about the first twenty minutes still be answerable two hours in.

Tidy the transcript

A speech model writes fragments. This rewrites each finished minute into readable prose — punctuation, sentences, paragraphs — leaving what was said unchanged. It needs a language model; without one the transcript is shown exactly as the speech model produced it.

Approximate. Each pass waits for the speaker to stop before it cuts, so it never breaks mid-sentence.

Timestamps stay in the cleaned-up text so a passage can be traced back to the moment it was said. Fewer of them reads better; more of them locates a claim more precisely.

Glossary

Picks out jargon as it is introduced and defines it from how the speaker used it, which is usually more useful than a textbook definition.

Retrieval

Pulls in earlier material that matches the question, rather than relying on the summaries alone.
