Location

A path on the machine running this application. One SQLite file per session, written as the talk proceeds rather than at the end — so a crash costs seconds, not the session.

Recording

Where Recorded and Window modes write their audio. Deliberately not the recordings library the file source replays from — one holds what this machine captured, the other holds what you gave it, and a single list mixing them is a way to delete the wrong thing.

min

A toggle is easy to forget, and an unattended microphone will fill a disk overnight. Reaching the limit stops cleanly and says so — everything captured up to it is transcribed.

s

The most audio the model is handed at once when transcribing a finished recording. Each piece is cut shorter than this wherever the speaker paused, so no piece starts or ends mid-word. Shorter moves the progress figure more often and makes a pause take effect sooner.

    Retention

    Off by default, deliberately. A recording of a room is a materially different thing to hold than a transcript of it, and it is also large — roughly 115 MB an hour.
    In Recorded and Window modes this decides what happens to the captured audio once it has been transcribed: with this off it is deleted, and with it on it is kept. Audio from a pass that failed is always kept regardless — it is then the only copy of what was said.

    {# **"Delete sessions after N days" used to be here, and nothing implemented it.** The setting was declared, the control was drawn, the value was saved, and no code ever read it — so anyone who set it believed their old recordings were being cleaned up while they accumulated. A control that promises to delete data and does not is worse than no control. It is not replaced by a working version on purpose. Deleting somebody's recordings on a timer is not a thing this application should do quietly, and there is already a considered tool for it: `scripts/prune_empty_sessions.py`, which reports by default and only deletes when asked with `--apply` (D-055). #}

    Nothing is deleted automatically. To clear out sessions that hold no transcript and no recording, run uv run scripts/prune_empty_sessions.py — it reports what it would remove and deletes only when you add --apply.
