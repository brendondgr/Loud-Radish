{# Global keyboard shortcuts (Plan 5). These are registered by the **companion process**, not by this page. A page in a browser tab cannot register a system-wide hotkey — under Wayland an application cannot grab keys at all — so the panel says plainly when the companion is not running and the bindings are therefore inert. A settings page that silently stores keys nothing listens for is worse than one that admits it. #}

Global shortcuts

Registered through your desktop's own shortcut service, which is the only sanctioned way under Wayland — and the reason they can be revoked from your system settings. This application never reads input devices directly.

Checking…

Keys

Starts, or stops if it is already recording.

Captures audio immediately, with no transcription until you stop.

Opens the options first rather than starting. Window capture has three switches that have to be answered before anything is captured, so this one asks.

Starting with your session

The shortcuts only work while the application is running, so it is worth having it start with your desktop. From a terminal in the project folder: 

uv run scripts/install_autostart.py

Removing it again is --uninstall on the same command. It writes one systemd user unit and nothing else.
